# 가품매장 관제 지도 (Fake Store Map)

우리 회사 정품 매장과 가품(위조품) 판매 매장의 현황을 카카오 지도 위에 함께 표시하고,
특정 매장을 클릭하면 **반경 내에 있는 상대 매장**을 분석해주는 관제용 정적 웹앱입니다.

## 🎯 핵심 기능

### 1. 지도 표시
- 🔵 **우리(정품) 매장** / 🔴 **영업중 가품매장** / ⚪ **종료 가품매장** 을 색상 마커로 구분
- 전국 매장을 한 화면에서 확인, 마커/목록 클릭으로 이동
- **줌 레벨에 따라 마커 크기 자동 조절** (축소=작게, 확대=크게)
- **마커 클러스터링**: 축소하면 가까운 매장들이 숫자 뭉치(파랑=우리, 빨강=가품)로 묶이고, 확대하거나 클러스터를 클릭하면 개별 마커로 펼쳐짐. 목록/마커 클릭 시 자동 확대되어 정확한 위치 표시

### 2. 반경 분석 (클릭 시)
- **우리매장 클릭** → 반경 N km 내 **가품매장 수·목록** 표시
- **가품매장 클릭** → 반경 N km 내 **우리매장·매출 영향도(높음/중간/낮음)** 표시
  - 영향도는 거리 가중(1km 이내 1.0 / 3km 이내 0.7 / 그 외 0.4)과 매장 수로 계산
- 반경은 슬라이더로 **1~20km 자유 조절** (기본 5km)

### 3. 검색 / 필터
- **검색어**: 매장명·주소·판매상품·상권·유형·코드·비고를 실시간 통합 검색
- **필터 4종** (가품 기준): 유형 / 영업여부 / 상권 / 판매상품
- 필터 값은 업로드된 데이터에서 **자동으로 생성**됨

### 4. 데이터 업데이트 (관리자 전용, 코드 수정 불필요) ⭐
- **사이드바 맨 하단의 작은 "🔒 관리자 데이터 관리" 링크**를 눌러 진입하며, **관리자 로그인 후에만** 업로드/초기화 도구가 열립니다.
  - 일반 사용자: 지도·검색·필터·반경 분석만 사용 (업로드 버튼 안 보임)
  - 관리자: 비밀번호 입력 시 도구 노출, 로그인 상태는 해당 탭 세션 동안 유지 (`로그아웃` 버튼 제공)
- 관리자 비밀번호는 `js/app.js` 상단의 `ADMIN_PASSWORD` 에서 변경 (기본값 `admin1234`)
- 엑셀(.xlsx/.xls) 또는 CSV 업로드 → 지도 자동 갱신
- **우리매장 파일**과 **가품매장 파일**을 각각 업로드
- **주소만 있고 위경도가 없으면 카카오 지오코딩으로 자동 좌표 변환**
- 업로드 데이터는 브라우저(localStorage)에 저장 → 새로고침해도 유지
- **엑셀 양식 받기** 버튼으로 표준 템플릿(.xlsx) 다운로드
- **초기화** 버튼으로 기본 데이터(map-data.json)로 복원

## 🎨 UI/디자인
- **레이아웃**: 네이버 지도 스타일 — 좌측 아이콘 레일 + 검색결과 패널 + 지도 상단 카테고리 칩 + 우측 지도 컨트롤 + 하단 중앙 "이 지역 다시 검색" 버튼
- **디자인/색상**: Apple 감성 — 화이트 배경, `-apple-system` 폰트, 큰 둥근 모서리, 반투명 블러(backdrop-filter), 포인트 블루(#007AFF)·레드(#FF3B30)
- **좌측 레일**: 지도 / 우리매장 / 가품매장 / 현황 / 🔒관리자
- **검색 패널**: 검색창, 지표(가품/우리 수), 반경 슬라이더, 필터 4종, 우리매장·가품매장 탭 목록
- **지도 컨트롤**: 지도/위성 전환, 줌 +/−, 내 위치, 카테고리 칩(=유형 필터 동기화), 패널 접기 손잡이
- **관리자 데이터 관리**: 우측 상단이 아닌 **모달 팝업**으로 분리(레일의 🔒관리자 클릭 → 로그인)

## 📱 모바일 대응
- **하단 탭바**: 데스크톱 좌측 레일이 모바일에서는 화면 하단 탭바(지도/우리매장/가품매장/현황/관리자)로 전환 — 엄지 조작에 최적화
- **바텀시트 패널**: 검색·목록 패널이 아래에서 올라오는 시트로 표시. 상단 **드래그 핸들**을 아래로 스와이프하거나 **"지도 보기 ✕"** 버튼으로 닫기
- **지도 전체화**: 지도가 화면 전체 배경. "🗺️ 지도" 탭 또는 매장 선택 시 패널이 자동으로 닫혀 지도가 바로 보임
- **플로팅 "목록·검색" 버튼**으로 언제든 패널 재호출
- **세이프에어리어(노치/홈바)** 대응, 화면 회전·리사이즈 시 지도 자동 재정렬, `100dvh`로 주소창 높이 변화 대응
- 터치 타깃 확대, 좁은 화면(≤400px)에서는 필터 1열 배치

## 🔑 카카오 지도 키
`index.html` 상단의 `window.KAKAO_JAVASCRIPT_KEY` 에 발급받은 **JavaScript 키**를 넣습니다.
카카오 개발자 콘솔 → 내 애플리케이션 → **플랫폼 → Web → 사이트 도메인**에
배포 주소(예: `https://...`)를 반드시 등록해야 지도가 표시됩니다.
> 주소→좌표 변환은 SDK의 `services`(geocoder) 라이브러리를 사용하므로 별도 REST 키는 필요 없습니다.

## 🔐 관리자 접근제어 안내
현재 데이터 관리는 **앱 내부 비밀번호 방식**입니다. 사내 실무자 구분 용도로는 충분하지만,
비밀번호가 클라이언트 코드에 포함되므로 **완전한 보안은 아닙니다**.
진짜 보안이 필요하다면 배포 후 **플랫폼 접근제어(로그인 계정/조직원 기반 라우트 차단)** 로 강화할 수 있습니다.
필요 시 요청해 주세요.
